1. Откройте лаунчер, перейдите в настройки (**OPTIONS**) на вкладку **Miscellaneous** и убедитесь в том, что установлена галочка **Use GameSpy proxy**. 
2. Если шаг 1 не помог — сгенерируйте конфиг ProtonVPN или WARP:

**ProtonVPN:**
Перейдите на [страницу](https://proton-generation.github.io/), нажмите **«Подключиться и получить серверы»**. После создания временного аккаунта выберите страну (для наименьшего пинга рекомендуем Нидерланды — **NL**) и нажмите **«Сгенерировать конфиг»**, затем **«Скачать .conf файл»**.

**WARP:**
Перейдите на [страницу](https://warp-generation.github.io/) и выберите любой из вариантов для **AmneziaWG**.

3. Установите [**AmneziaWG**](https://github.com/amnezia-vpn/amneziawg-windows-client/releases/latest)
4. Откройте **AmneziaWG**, нажмите на **Добавить туннель**, далее нажмите на **Добавить пустой тоннель** и импортируйте файл с конфигурацией из п. 2.
5. Выберите импортированную конфигурацию  и нажмите **Подключить**.
